# test_simulation
Προσομοίωση γραπτής εξέτασης στη SDY60

### Ανάπτυξη εφαρμογής

<img width="350" height="800" alt="1780987785778" src="https://github.com/user-attachments/assets/beda12b7-ccd2-4571-9dfd-4ceda77ada1c" />

Η παραπάνω οθόνη είναι μια οθόνη εφαρμογής για τη μέτρηση των καρδιακών παλμών και αρτηριακής πίεσης του χρήστη. Όπως βλέπουμε απεικονίζεται η τίμη της μέτρησης των καρδιακών παλμών και γίνεται ένας χαρακτηρισμός αυτής της μέτρησης ως προς την υγεία του ασθένη σύμφωνα με τα ιατρικά πρότυπα ("κανονικός").
